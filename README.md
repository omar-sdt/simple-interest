# Simple Interest Calculator

Bash calculator for the IBM Getting Started with Git and GitHub final project.

## Inputs and formula

- Principal amount (p)
- Annual rate of interest, as a percentage (r)
- Time period in years (t)

Simple interest = p * r * t / 100.

## Run

```bash
bash simple-interest.sh
```

Example: principal 1000, rate 5, time 2 produces `Simple interest = 100.00`.
Non-numeric and negative inputs are rejected. Requires Bash and awk.
